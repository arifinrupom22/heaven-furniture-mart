PROJECT NOTE — HEAVEN FURNITURE MART
RacDox Hackathon 2026

Since the challenge specifically asked for a landing page rather than a complete e-commerce website, I intentionally kept the experience focused and conversion-oriented.

Some elements that could normally lead to separate pages or additional content have been implemented as internal/default navigation instead. This keeps the landing page clean while still making the interface feel complete and functional.

For example, the Collection section contains different furniture categories such as Living Room, Bedroom, Dining Room, etc. Since this submission is a single landing page and does not include separate category pages, clicking these items takes the user back to the main landing-page experience rather than leading to unfinished or non-existent pages.

This approach was intentional to avoid adding unnecessary pages or placeholder content while keeping the overall user experience consistent with the scope of the challenge.

The primary conversion action throughout the page is:
"Request a Quote"
